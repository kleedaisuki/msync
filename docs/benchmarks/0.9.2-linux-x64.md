# msync 0.9.2 Linux x64 distribution-suite baseline

2026-11-20 · packaged Linux x64 Native AOT · single-version baseline.

This is the first baseline for the revised six-group default suite, plus both
opt-in SSH directions. It does not replace the historical 0.9.1/0.9.2 paired
experiments or compare against a different workload matrix.

## Reproduction

- Suite revision: `2b947bba88617290217a4cf549587cce59c1d0e1`.
- Published executable SHA-256:
  `abae29d71784fb5b7830ea2e905b97fb3b08e9b09cd7a424c20c1ca3babd9db0`.
  Adjacent `libe_sqlite3.so`:
  `b0f5c48026fedcf9f05cf31c6fadf9e001ca59cd85aa68b8b6814e52c18a07`.
- Debian 13 guest, Linux 6.12.113, ext4, KVM/QEMU Virtual CPU 2.5+,
  16 visible vCPUs. The harness and descendants were pinned to logical CPU
  6. SSH used same-host OpenSSH 10.0p2 with public-key authentication and
  multiplexing disabled. Client and server shared that pinned CPU and
  filesystem. No WAN delay or disk cache eviction was imposed.
- Standard size, seed 17, Auto tiering, telemetry off. Seven observations
  and one warmup where supported. Editor observations are fresh sessions;
  PTY cases each retain 256 sequential submissions in four age windows.
  Oracle work is outside the latency timers.

```sh
python3 tests/Performance/run.py --binary PATH_TO_092_MSYNC \\
  --cpu 6 --samples 7 --warmups 1 --seed 17 --scale standard --route both \\
  --io-transport local --io-transport ssh-loopback --io-transport ssh-download
```

The [portable sample receipt](0.9.2-linux-x64.json) retains measurement
boundaries, input characteristics and samples without checkout-local paths.
Full local receipts and logs are under
`artifacts/benchmarks/distribution-baseline-092-linux-x64/`.

## I/O

End-to-end source CLI P50 in milliseconds, first deploy / redeploy. Each cell
has seven independently verified observations. Redeploy is a whole-tree
merge after the specified changes, not a delta transfer.

| Profile (first-deploy files / MiB) | Local | SSH upload | SSH download |
| --- | ---: | ---: | ---: |
| Source tree (377 / 5.53) | 459 / 459 | 1,672 / 1,756 | 987 / 966 |
| Mixed release (100 / 4.75) | 153 / 156 | 625 / 671 | 586 / 570 |
| Artifact batch (103 / 45.75) | 228 / 276 | 1,072 / 1,136 | 1,086 / 1,081 |

The source tree is slower than the artifact batch locally and for upload,
despite selecting far fewer bytes. Download does not show the same ordering.
These are differences between workload shapes, not isolated effects or a
causal split of filesystem, protocol and process time. All 84 measured SSH
commands used one client, one authentication and one session each.
