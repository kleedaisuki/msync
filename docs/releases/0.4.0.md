## Install / 安装

**Windows 10/11 x64:** download `msync-0.4.0-windows-x86_64-setup.exe`.
The installer needs no administrator rights, installs into `%USERPROFILE%\.msync`,
adds its `bin` to your User PATH if selected, and provides a Start Menu REPL.
Restart an existing terminal application before expecting its PATH to refresh.
Uninstall removes packaged files and installer-owned PATH entries, not your data.

**便携使用：** download/extract `msync-0.4.0-windows-x86_64.zip` and run
`bin\msync.exe --help`. No Rust compiler or Visual C++ Redistributable is required.
Linux x86-64 users can extract the tarball (glibc 2.35+, built on Ubuntu 22.04).

The Windows executables are currently **unsigned**. Windows may display a
publisher/SmartScreen warning; verify this official repository and the matching
`SHA256SUMS` rather than disabling system protection. Checksums detect corruption,
not a trusted Authenticode publisher identity. Optional SSH/HTTP/WSL transports
use your system's OpenSSH/curl/WSL; setup does not enable capabilities or install
an SSH service. Existing OpenSSH configuration stays managed by OpenSSH.

## What's new

- Reuse native SSH Host names, including exact Unicode/configuration aliases.
- Correct cancellation/retry around authentication; contextual native Windows
  credential windows with masked Unicode input and owned-process cleanup.
- Better live REPL highlighting and colon-command completion.
- Export, bind and reuse relocatable/contextual IR without stale filesystem proofs.
- Faster large small-file plans through cached demand-class scheduler admission.
- Per-user Windows setup, portable archives, matching license notices and checksums.

Start safely with `msync check FILE`, `msync plan FILE`, or
`msync run FILE --dry-run`; an ordinary `run` writes real files. The tool is
one-way copying/streaming, not a deletion/bidirectional/watch daemon.

msync does not yet load a standalone `~/.msync/config.toml`; installation preserves
such user-owned files without claiming to interpret them. SSH passwords are not
stored in configuration, history or exported IR. Full usage/design notes and GPL
license are bundled with every package; matching source is available below.
