# msync 0.7.1

This patch fixes endpoint-distribution macros introduced in 0.7.0. When a scope
comes from a runtime loop, compact `scope::file` now selects the value of the
path parameter instead of a literal filename `file` in the endpoint's cwd.

The following works without the `(scope)::file` workaround:

```text
forge => ssh://forge
myvpn => ssh://myvpn
wsl => $wsl

macro copy_to(scope, file):
    $local::file -> scope::file

for scope in [wsl, myvpn, forge]:
    for file in [~/.codex/AGENTS.md, ~/.codex/codex.prompt]:
        copy_to(scope, file)
```

Unqualified home paths still resolve on the selected endpoint; quoted filenames
remain literal. Normal-copy/retry semantics and existing object compatibility
are unchanged. Recompile previously compiled affected objects or IR from their
source: upgrading does not rewrite operands already compiled as literal names.

## Packages and verification

All native executables are rebuilt from this release's source. The Windows
installer and portable ZIP use the same corrected MSVC build. Their actual
installed-program acceptance compiles nested endpoint/path macro loops, removes
the source, executes the object, and checks both destination files' bytes.
The Linux package runs the same source-free regression journey.

Local checks cover the reported macro through source, source-free objects and
IR using the production shell/archive protocol with separate endpoint homes,
plus related standard-library and scope-returning function journeys, formatting
and strict changed-target Clippy. The shell harness is not a native WSL test.

Release assets:

- `msync-0.7.1-windows-x86_64-setup.exe`: per-user Windows x64 installer.
- `msync-0.7.1-windows-x86_64.zip`: portable Windows x64 package.
- `msync-0.7.1-linux-x86_64.tar.gz`: Linux x64, glibc 2.35 or later.
- `msync-language-0.7.1.vsix`: VS Code extension.
- `SHA256SUMS`: checksums covering all four assets.

Previously published tags and asset bytes are not replaced. The
[integration record](../design/integration-v070.md) tracks published identities
and native package acceptance.
