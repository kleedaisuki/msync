# msync 0.7.2

This release aligns the language frontend and VS Code experience around the
existing inferred type system and typed executable IR.

## Operators and inferred values

- `$` is an explicit unary reference operator for lexical bindings and built-in
  values. `$local` and `$ local` both produce a Scope that can be passed to an
  ordinary function or macro.
- `::` is binary selection/qualification and `/` is binary path composition,
  with or without spaces. Every `String × String`, `String × Path`,
  `Path × String` and `Path × Path` join produces a Path. A String otherwise
  remains String: a quoted transfer source is content, not a filename.
  `"C:\Users\STONE\.codex"/codex.prompt` follows this same rule, without a
  Windows-specific conversion.
- Operator admission uses inferred operand types. Lexical namespaces select
  declared members; filesystem scopes qualify paths. Native declarations remain
  the typed host interface, with explicit argument/result/effect capabilities.
- A path formed from String values is not reparsed as selector syntax. For
  example, `"."/"<literal>"` remains Path. To request a range, write an explicit
  unquoted selector such as `"directory"/<.*>`, rather than embedding it in a
  quoted filename. Existing compiled selector objects retain their typed behavior.
- The runtime continues to execute typed IR, not source text. Existing object
  compatibility, endpoint provenance and ordinary copy/retry semantics remain.

```text
macro copy(scope, file):
    scope::file -> "backup"/file

copy($local, .codex/codex.prompt)
```

## VS Code

- Highlight `$`, `::` and `/` as operators rather than swallowing them into
  namespace/path tokens. Keep quoted strings, selectors and URLs intact.
- Complete local files and directories after `$local::`, including hidden
  directories and quoted filenames. Apply completions as valid source expressions
  and continue into directories without authenticating remote endpoints.
- Keep standard-library navigation, signatures and diagnostics backed by the
  same compiler and embedded standard sources as execution.
- Show compiler-inferred Scope, String, Bool and Path types on binding hovers.
  Restart language services from `msync: Restart Language Server`; changing
  `msync.serverPath` reconnects automatically, and startup errors link to settings.

## Packages

- `msync-0.7.2-windows-x86_64-setup.exe`: Windows x64 per-user installer.
- `msync-0.7.2-windows-x86_64.zip`: Windows x64 portable package.
- `msync-0.7.2-linux-x86_64.tar.gz`: Linux x64, glibc 2.35 or later.
- `msync-language-0.7.2.vsix`: VS Code extension.
- `SHA256SUMS`: checksums covering all four assets.

Installed acceptance exercises all four String/Path join pairings, references
and qualification through source-free objects. Editor acceptance
uses a real VS Code extension host. Published tags and asset bytes are immutable.
