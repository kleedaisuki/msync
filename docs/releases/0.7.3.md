# msync 0.7.3

Release candidate notes; publication is on hold pending user review.

## Literal Strings, without backslash escapes

Ordinary double-quoted Strings preserve backslashes exactly. There is no raw
String prefix, no escape String prefix and no Windows-path recognition rule.

```text
source := "D:\Code\agents\target\xmlsquish\artifacts"/codex.prompt
source -> copied.prompt
```

`\t`, `\n`, `\r` and `\\` are literal character sequences. A quote inside a
String uses a doubled quote delimiter (`"say ""hello"""`), and actual newline
content can span physical lines. Parsing, formatting, highlighting, REPL
accumulation and version-header detection share these String boundaries.
Command-looking and header-looking lines inside Strings remain data.

This fixes the reported `\target` path becoming `agents<TAB>arget` before
filesystem completion. No decoded character is guessed back into a backslash.

## Bare filesystem completion

Ordinary file and directory names now insert bare Path operands:

```text
$local::.codex/codex.prompt
```

Names with whitespace are quoted. Grammar-reserved or lexically shadowed names
are quoted only where needed to select the actual filesystem entry rather than
a same-spelled value. Completion continues through quoted directory bases and
supports literal backslashes, trailing separators and doubled quote delimiters.

URI highlighting separately identifies the protocol, `://` operator and endpoint
address, including `ssh://forge`; quoted URL text remains ordinary String data.
The runtime still receives one complete typed endpoint value.

Typed operator and explicit-reference errors also retain nearest visible binding
suggestions without changing inferred operand types or operator-owned locations.

## Source migration and object compatibility

Remove backslash doubling previously added solely for String escaping. To place
an actual newline in String data, use an actual newline, not `\n`. Existing
objects and JSON IR retain their already-compiled literal bytes; the runtime
does not reparse debug source. Recompile affected source to correct paths that
were previously compiled with unintended control characters.

The native Windows acceptance journey uses real `target\new\runtime` directories
with directly pasted single-backslash source and verifies both copied bytes and
the exact native path String. Real editor/LSP journeys verify bare completion
edits and formatting before execution. Previously published tags/assets remain
unchanged.
