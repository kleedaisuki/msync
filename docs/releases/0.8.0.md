# msync 0.8.0

msync 0.8.0 is the .NET 10 Native AOT implementation of the typed expression
language. It ships native Linux x86-64 and Windows x86-64 packages, a Windows
installer, and the matching VS Code extension. The portable product requires no
installed .NET runtime.

## Language

- Braces define blocks; the final expression is their result. `;` discards a
  value. Empty and discard-only blocks return `null`.
- `let` bindings and Scope fields are mutable, while their inferred or declared
  storage types remain fixed. A new declaration shadows an existing location.
  Closures share captured locations, and Scope aliases retain instance identity.
- Null admission is explicit: `let value? = ...` and `field?: ...`. `value?`
  means **is null**, not is-present. Conditions require Bool, and non-null uses
  retain control-flow refinements, including delayed Range composition.
- `fn` is generic by default, supports recursion and callbacks, and accepts
  parameter and result constraints. Named Scopes initialize once per program or
  REPL session; anonymous Scopes construct fresh instances. `global` imports
  definition-time ancestor locations.
- `concept` expresses structural member and callable requirements. Inline
  `typename` binds associated types without adding runtime type kinds.
- Number is binary64, with decimal/scientific/base literals, IEEE comparisons,
  signed zero, `%` and right-associative `**`. Integral counts and indices support
  the platform's Int64 iteration domain.
- `as` selects explicit conversions. Only Path and String convert implicitly.
  `Scope::member` is lexical selection; `path @ connection` qualifies a physical
  endpoint. Paths remain callable and produce Process values.
- `match` is exhaustive over the inferred domain and accepts type and regex
  patterns. `decltype` and dependent metadata queries do not execute operands.

```msync
concept Product {
    first?: typename First,
    second?: typename Second,
};

fn copy(source: Path, destination: Path) -> Bool {
    source -> destination
};

let source? = if exists ~/.codex { ~/.codex } else { null };
if source is not null {
    copy(source, ~/.config/codex)
};
```

## Source-backed standard library

The library uses PascalCase Scope families and snake_case associated functions
with explicit instance arguments. Instances contain data and selected policies,
not a set of getter closures allocated for each object.

- `$std::data::{Pair,Option,Result,Either}` provides product, optional and sum
  composition. `Option::some(null)` is distinct from absence.
- `$std::concepts` supplies reusable data, callable and policy contracts.
  `$std::meta` provides type classification, relationships, transformations and
  unevaluated invocation/member queries for generic policy selection.
- `$std::containers` includes List, Map, EqualitySet, Stack, Queue, BTree,
  BPlusTree, red-black Set and Heap. Trees implement splitting, balancing,
  deletion and ordered traversal; node/page storage is reused and retired
  payload references are released. Comparators are explicit policies.
- `$std::files`, `$std::commands`, `$std::text` and `$std::regex` supply file and
  process specifications, launch/exit policies, StringBuilder and Pattern.
  `io` and `process` retain the underlying host primitives.
- `$std::shell` provides typed terminal tools such as `ls`, `cat`, `cp`, `mv`,
  `find`, `grep`, `head`, `tail`, `sort` and `wc`. REPL entries are ordinary
  language bindings; there is no second shell-string grammar.

See the [library contract](../design/stdlib-v080.md) and the runnable
[ordered-container example](../../examples/ordered_containers.msync).

## Execution and optimization

`.mso` is relocatable typed bytecode. `.mexe` binds execution context and
specializes operations; it is not an OS-native executable. Both run after source
deletion and never replay debug source. Current artifacts use format **4**.

Default optimization is **O2**. The optimizer combines control/data-flow,
constant evaluation, inlining and specialization, dead value/store elimination,
Scope scalarization, and memory-value reuse. This release adds dependency-local
analysis invalidation and successful indexed Buffer read reuse. Closed Native
call domains lower directly without unnecessary wrapper frames. IEEE behavior,
first failures, aliases, and acquire/release boundaries are preserved.

Number intermediates remain unboxed on the operand stack. Native callbacks are
cached per interpreter, and standalone programs demand-load standard exports
without changing mutable module cells or future REPL visibility. Contextual
binding optimizes once; executing `.mexe` does not rebind or repeat optimization.

Transfers use same-directory staging and atomic replacement, not a persistent
rollback journal. Failures retain actual causes, completed cohort members may
remain, and retry is supported. Selected remote work uses native SSH with its
configured agents/prompts; checks and unselected branches do not authenticate.

## REPL and VS Code

The REPL includes lexical highlighting, hints, typed completion, streamed Range
display and cancellation. Session `cd` does not change the host process cwd or
reanchor existing paths. Live Process handles can escape through values and
persist between submissions, so stdin/control and explicit waits remain usable.

The extension supplies semantic highlighting, useful type/signature hover,
diagnostics, formatting, symbols, completion and source navigation. `.mso` and
`.mexe` open as read-only typed IR with highlighting and navigation; viewing
does not execute, bind or authenticate. Windows human output uses UTF-8 without
changing input encoding; embedded standard sources retain their authored LF
literal values on both platforms.

## Migration and installation

This is a language transition from 0.7.x. The indentation grammar, macro/symbol
declarations and old object formats are not supported. Convert scripts to the
0.8 syntax and recompile artifacts. The Rust implementation and its dispatch
entrypoints have been removed; historical source remains in the 0.7.x Git tags.

Install the complete Native package, keeping its native SQLite library and
notices beside the executable. Install the matching extension:

```text
code --install-extension msync-language-0.8.0.vsix --force
```

Reload VS Code and restart the language server. When multiple installations
exist, set `msync.serverPath` to the intended executable's absolute path; it is
not a shell command. `SHA256SUMS` covers the Linux archive, Windows portable ZIP,
Windows installer and VSIX. Project sources and third-party notices accompany
the matching version tag and packages.

The C# source tree is organized by component responsibilities. This cleanup
does not change language behavior, the CLI/native API, or the artifact format.
See [architecture and source ownership](../design/architecture-v080.md) and the
[packaging contract](../design/packaging-v080.md) for build and validation details.
