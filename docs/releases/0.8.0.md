# msync 0.8.0 development delivery

This is the C#/.NET 10 Native AOT language transition. It does not declare a
public release publication or replace any already published artifact.

## Source migration

The new grammar uses `let`, `fn`, `{ ... }` blocks and `;`. A semicolon discards
the expression value; an unterminated block tail returns it. Empty/discarded
blocks produce Null. `?` explicitly admits Null, `value?` means `value is null`,
and non-null consumers require branch or exhaustive-match narrowing. Type and
regex patterns participate in `match`; `decltype` is unevaluated. Connections
are distinct from lexical Scope values. Paths remain callable process values.

The Rust 0.7.3 implementation is retained under `legacy/` as an independently
buildable semantic baseline. `msync legacy ...`, old explicit grammar versions,
and old object extensions route to a separately available baseline executable
or provide its build command. No old bytecode is silently given new meaning.

## Compiler and runtime

Typed function specialization produces explicit binary bytecode. `.mso` files
retain relocatable context; `.mexe` files bind working directory, home and source
context. Both execute after source deletion. The optimizer and runtime lowerer
operate on bytecode, not debug source. Native host capabilities carry signatures,
dependent range result rules and effects, while ordinary compositions remain
embedded executable `stdlib/*.msync` source.

The copy model remains normal same-directory staging and atomic replacement,
not persistent rollback. Failures report actual causes; completed cohort members
can remain and be retransmitted. Native remote authentication belongs to
selected work, not checking or unselected endpoints.

## Delivery evidence

- A strict local .NET build and Linux Native AOT publish pass without warnings.
- Real source/check/dry-run, `.mso`/`.mexe` source deletion and byte comparison
  journeys pass, including the installed-layout native SQLite dependency.
- The native VS Code 1.144 host passes typed diagnostic repair, formatting,
  function navigation, completion, hover, symbols, semantic ranges and restart
  without performing DSL transfer effects. A separate URI journey passes ten
  complete/incomplete URI forms and quoted-String separation.
- CLI journeys exercise global options before subcommands, lossless String
  formatting, binary stdout and persistent REPL bindings without replaying prior
  effects.

Focused language, native transport, configuration, observability and performance
evidence is retained in the relevant `docs/design/*-v080.md` notes. Native Windows
and installer acceptance run on the configured Windows workflow; Linux evidence
is not relabeled as Windows execution.

## Build

```text
dotnet build msync.slnx
python3 scripts/check_local.py --journey cli
python3 packaging/build.py --rid linux-x64 --smoke
```

The portable product needs no installed .NET runtime. Its native SQLite library
ships next to the executable; the package includes upstream attribution and
checksums. The VSIX and package versions agree with `Directory.Build.props`.
