# msync 0.8.1

## Typed HIR development

The 0.8.1 work separates source semantics from bytecode generation through an
explicit typed high-level representation. Binding identities, fixed storage
constraints, value reads, captures, control flow and callable specialization
belong to semantic analysis. Stack slots, instruction selection and branch
offsets belong to bytecode lowering.

The product version is 0.8.1. The existing bytecode format and language-semantic
version remain independently versioned; published 0.8.0 object and executable
files must retain their semantics. The new high-level file format has its own
version and does not embed bytecode or replay source syntax.

The release record will include the finalized HIR commands and layer contract,
compiler time/allocation observations, source-free export/lowering journeys,
and Native Linux, Windows, REPL and editor acceptance from the released source.
