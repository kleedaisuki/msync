# msync 0.9.0

msync 0.9.0 ships as a self-contained .NET Native AOT application. Install
the complete Linux x86-64 or Windows x86-64 package; no separate .NET runtime
is required. The matching VS Code extension is `msync-language-0.9.0.vsix`.

## Language and editing

Concepts can now name type parameters, constrain them with a type or another
concept, and compose parameterized base concepts:

```msync
concept Cell<T> { value: T, };
concept Named { name: String, };
concept Entry<T: Named> : Cell<T> {};
concept Input<T: Path | String> { value: T, };
```

Use `Cell<String>` to fix an argument or a bare `Cell` to infer it. Concept
arguments are checked at compile time and do not add runtime tags or alter a
Scope layout.

- `continue;` skips to the next iteration of its enclosing `for` or `loop`.
- `msync fmt` terminates named `fn` and `scope` declarations with `};`.
  Anonymous expressions keep their surrounding delimiters. Older source
  omitting these declaration terminators still parses.
- The VS Code grammar separates control flow from declarations and other
  keywords, and supports generic concept headers and type-parameter navigation.
- Ordinary calls and Range literal initializers now evaluate immediately.
  Traversal adapters still invoke callbacks on demand. For a callback that must
  observe a later assignment, pass a closure that reads the binding, such as
  `fn(value) { current(value) }`, instead of passing the current function value.

## Compiler and runtime

The compiler carries static layouts, typed storage and call plans from HIR
through LLVM IR into the native execution model. Known fields use their
compiled layouts, and eligible guest calls and storage operations use direct
native paths. Ordinary specialization uses the static inputs the body needs,
not a copy of the caller's object graph. Redirected standard input no longer
dispatches a separate thread-pool task for each line.

Existing CLI telemetry can inspect compiler phases, specialization and
optimizer decisions, artifact preparation, and execution. The Native AOT
build of the host is separate from msync's embedded guest JIT.

## Upgrade from 0.8

**Recompile existing build artifacts from source.** `.mso` and `.mexe` now use
Native format **2**; `.mhir` uses HIR format **4**. Older binary artifacts are
not imported or executed. The source-language contract and embedded
standard-library URI version remain **0.8.0**.

See the [language contract](../design/language-v080.md), the
[Native runtime and artifact model](../design/native-model-v090.md), and the
[installation instructions](../../README.md#build-and-run).
