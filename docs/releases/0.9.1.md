# msync 0.9.1

- Type unions use `or` rather than `|`. Type intersections and complements use
  `and` and `not`; the expression pipe `|` is unchanged.
- `is`, `let … else`, and guarded `match` support compound patterns, bindings,
  and structural destructuring. Only `match` requires exhaustive coverage.
  Different-width Range patterns share a bounded, demand-driven cursor.
- Add named generic parameters, local type inference, type projections from
  correlated candidates, and unevaluated `decltype` in concept requirements.
- Add inclusive `a..b`, lazy Range comprehensions, named call arguments,
  expression-bodied functions, anonymous Scope literals without `scope`,
  field shorthand, and null-coalescing operators.
- Fix Windows SSH transport argument handling and REPL recovery after failed
  subprocesses; preserve SSH channel ownership during Range transfers.

The Linux and Windows packages use .NET 10 Native AOT. The separate VS Code
extension uses the installed CLI as its language server. Recompile source with
the new compiler to use the new syntax and HIR operations. Existing v0.9.0
publication assets are not replaced.
