# msync 0.9.2

- Make repeated fixed calls stay in native code where the linked frame and
  live argument state allow it. Generated code builds and retires guest stack
  frames; a cold exit resumes the original frame without replaying effects.
- Move more Scope, closure, and Range storage into the native guest heap.
  Native Range plans cover eligible traversal, windowing, ordering, and
  callbacks while preserving lazy demand and callback order.
- Improve executable binding and inlining, physical argument placement, and
  direct native reference operations. These are runtime and compiler changes,
  not changes to the standard-library Set implementation.

On one frozen Linux x86-64 Set workload, removing repeated host call admission
cut paired median elapsed time by 10.02% against the preceding candidate
(19 of 19 pairs faster). The [technical record](../design/native-execution-lowering-v090.md#reuse-fixed-call-admission-inside-a-native-stretch)
describes the comparison and its limits.

Linux and Windows packages use .NET 10 Native AOT. The separate VS Code
extension uses the installed CLI as its language server. Rebind from source
with this version to pick up the new compiler and binding optimizations.
