# Runtime source map

The runtime executes typed bytecode; it does not parse source or replay debug
text. Public entry points remain in the `Msync.Runtime` namespace. Contextual
binding and lowering come from `Msync.Optimization`; semantic values and the
bytecode contract come from `Msync.Core`.

| Directory | Responsibility |
| --- | --- |
| `Execution` | Interpreter entry/lifetimes, opcode dispatch, invocation, local state, iteration, image projection, and the public persistent `ExecutionSession` |
| `Scheduling` | Invocation work ownership, process/deferred-flow reachability, directional ordering, and the independent resource-prefix dependency index |
| `Context` | Execution options/observations and invocation-owned path/cwd projection |
| `Native` | Static native dispatch and grouped filesystem, process, Range, scalar, text, metadata, and indexed-storage implementations |
| `Transfers` | Local/remote copy selection, owned staging files, archive transport, overlap handling, and selected queries |
| `Platform` | Native file identity/metadata, executable/search admission, and Windows file-copy APIs |
| `Text` | Unicode scalar casing implementation |
| `Generated` | Pinned Unicode tables, regenerated by `scripts/generate_unicode.py` |

`Interpreter` partial files operate on one invocation/session execution state.
The separate files distinguish dispatch, invocation, scalar operations and
scheduling without adding service forwarding or a second evaluator.
`ExecutionSession` owns persistent locals and cwd; `SessionImage` owns the shared
published code image. They are distinct classes, not declarations appended to
the interpreter implementation.

`ResourceIndex` owns its prefix trie and registration leases independently of
the interpreter. Its query and retirement algorithms are unchanged by source
organization. `IndexedStorageOperations` and `TextBuilderOperations` likewise
own their self-contained backing-store/chunk algorithms. `NativeRegistry` keeps
the finite static dispatch boundary; no runtime reflection or extra interface
dispatch is needed to select those implementations.

Path origins, shared cells, escaping Process ownership, Range retained roots,
and temporary-file publication follow the contracts in
[`runtime-v080.md`](../../docs/design/runtime-v080.md) and
[`mutable-state-and-effects-v080.md`](../../docs/design/mutable-state-and-effects-v080.md).
Changing source location or class ownership must not change those lifetimes,
native operation identities, or serialized artifact semantics.
