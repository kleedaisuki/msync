# Runtime source map

The runtime executes native typed IR; it does not parse source, replay debug
text, invoke the compiler or replan executable artifacts. `NativeInterpreter`
and `NativeExecutionSession` live in `Msync.Runtime.Native`; shared options,
observations and host mechanisms live in `Msync.Runtime`. The runtime depends
on `Msync.Core`, not the optimizer.

| Directory | Responsibility |
| --- | --- |
| `NativeModel` | Interpreter/image/frame, typed storage, native builtins, work ownership, host I/O, contextual preparation and transfer plans |
| `Scheduling` | Resource-prefix dependency index and neutral scheduling statistics |
| `Planning` | Portable resource-index and resource-identity helpers shared with native preparation |
| `Context` | Execution options |
| `Diagnostics` | Observations, timeline and actual native instruction/allocation profiles |
| `Native` | Word32 operations, lexical path parsing and local/remote process controls |
| `Transfers` | Resource path semantics, shell transport source, owned staging publication and overlap handling |
| `Platform` | Native file identity/metadata, executable/search admission, and Windows file-copy APIs |
| `Text` | Unicode scalar casing implementation |
| `Generated` | Pinned Unicode tables, regenerated by `scripts/generate_unicode.py` |

`NativeInterpreter` owns activation state, pending work and its image generation.
`NativeExecutionSession` preserves canonical locations and cwd across submissions.
An old suspended activation retains its own immutable image generation; it must
not reinterpret registers or constants using a later submission's ABI.

`NativeValue` is the closed builtin sum from Core. Monomorphic fields use their
actual primitive/root representation. Namespace operations use computed layout
offsets and guarded finite projections, not generic Scope/Cell objects or named
member lookup. Collections are source programs using logical Scope allocation;
there is no native arena/vector/slot-owner registry.

`NativePreparation` is an explicit pre-execution phase over bound native IR.
It may freeze selected contextual observations and portable transfer plans;
the execution VM consumes that result without calling preparation. The
`ResourceIndex` prefix trie and registration leases enforce actual selected
transfer/native hazards independently of language values.

Path origins, shared cells, escaping Process ownership, Range retained roots,
and temporary-file publication follow the contracts in
[`native-model-v090.md`](../../docs/design/native-model-v090.md) and
[`mutable-state-and-effects-v080.md`](../../docs/design/mutable-state-and-effects-v080.md).
Changing source location or class ownership must not change those lifetimes,
native operation identities, or serialized artifact semantics.
