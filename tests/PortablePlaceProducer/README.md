# Portable typed places

From the checkout root:

```sh
dotnet run --project tests/PortablePlaceProducer -c Release
python3 tests/PortablePlaceProducer/journey.py --binary /absolute/path/to/msync
```

The producer probe removes source text, round-trips the finalized HIR, then
lowers to portable code and round-trips that image through the actual reader
and validator. The fixture separates construction domains from structural
storage constraints, and concrete callable contracts from open template
identities. Exact field cases carry a layout and logical ordinal; no field
name is encoded as an execution operand. A genuinely opaque producer
uses a selected admission or an open projection, not an invented layout.

The real-process journey scores direct source, detached `.mso`, and detached
`.mexe` at O0 and O2 on both input branches. It checks distinct field ordinals,
mutation through an alias, structural rebinding of a typed input, raw
capture aliasing, selected native-produced Scope admission, and repeat use of
a named declaration whose initializers execute once in source order.
