# Source-free native worker preparation

Run from the repository root:

```sh
dotnet run --project tests/PreparedMethods -c Release -p:RestoreLockedMode=true
```

Independent format-6 objects and executables with typed signatures exercise raw Word32 through
a CFG join and backedge, the distinct observable Number signed-zero view,
checked external and computed shift counts, and rejection before an
unadmitted effect. The same compiler derives arena dynamic child selection,
writes actual primitive lanes before a canonical publication exit, and
retains the original owner at that exit. The vector case proves its
inductive index bound and declines an unchecked branch.

To check current real artifacts, pass the actual numeric Set and Heap
files produced by the current standard library after `--current`.
The object is bound without source or HIR. The numeric arena lookup runs
against independent ordered trees whose physical row indices are shuffled,
checking empty, odd, even and IEEE edge cases. The Heap artifact must
derive a whole vector sift with both native stores. These are compiler
proof tests; actual executable page publication, live storage admission,
platform behavior and timing are checked separately in CLI journeys.
